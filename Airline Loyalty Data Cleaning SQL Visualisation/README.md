# Airline Loyalty Data Cleaning, SQL & Visualisation

End-to-end analysis of an airline loyalty programme dataset: source CSVs are cleaned for MySQL import, explored with SQL, and presented in a dashboard deck and campaign report.

## Contents

- `01_Original_Data_Airline+Loyalty+Program/` — source CSVs and data dictionary.
- `02_Cleaned_for_SQL_Import/` — reproducible pandas cleaning script and MySQL schema.
- `03_A_Airline_Loyalty_Exploratory_Analysis_Queries.sql` — exploratory and segmentation queries.
- `04_Airline_Loyalty_Dashboard.pptx` — dashboard presentation.
- `05_Airline_Loyalty_Program_2018_Campaign_Report.pdf` — campaign report.
- `AmazonQuick_Dashboard_Building.png` — dashboard preview.

Run `clean_airline_loyalty.py` from its directory after installing `pandas` and `numpy` to regenerate SQL-ready CSV outputs locally. Those generated exports are intentionally not committed.
